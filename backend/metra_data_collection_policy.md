# Metra 数据收集政策

## 核心原则
1. **合法合规是底线**
2. **透明度是关键**
3. **用户利益优先**

## 数据收集层级

### 第一层：搜索引擎API（推荐）
- **合法性**：100%合法
- **数据类型**：标题、摘要、URL
- **适用场景**：大部分AI训练任务
- **成本**：低（$5/1000次）

### 第二层：官方API（推荐）
- **合法性**：100%合法
- **数据来源**：
  - 学术：arXiv、PubMed、Semantic Scholar
  - 新闻：NewsAPI、Guardian API
  - 社交：Twitter API、Reddit API
  - 知识：Wikipedia API、Wikidata
- **成本**：多数免费或低成本

### 第三层：合规网页获取（谨慎使用）
- **合法性**：需要验证
- **使用条件**：
  1. 网站在白名单中
  2. robots.txt允许
  3. 遵守使用条款
  4. 控制请求频率
- **工具**：ScrapingBee（仅用于合法网站）

## 技术实现

### 白名单管理
```python
WHITELIST = {
    "wikipedia.org": {"license": "CC BY-SA"},
    "arxiv.org": {"license": "Open Access"},
    "pubmed.ncbi.nlm.nih.gov": {"license": "Public Domain"},
    # ... 更多白名单网站
}
```

### 合规检查流程
1. 检查URL是否在白名单
2. 验证robots.txt
3. 检查请求频率限制
4. 记录数据来源和许可

### 用户透明度
- 显示数据来源
- 标注许可类型
- 提供原始链接
- 说明使用限制

## 用户条款建议

在Metra用户协议中包含：

```
数据使用声明：
1. Metra仅从公开、合法的数据源收集信息
2. 所有数据收集遵守相关法律法规和网站条款
3. 用户需对其使用收集的数据负责
4. 禁止将数据用于非法或侵权目的
```

## 风险管理

### 技术措施
- 自动过滤黑名单网站
- 限制请求频率
- 缓存常用数据
- 定期审查白名单

### 法律措施
- 定期咨询法律顾问
- 跟踪法规变化
- 保留合规记录
- 用户免责声明

## 最佳实践

### DO ✅
- 优先使用官方API
- 始终检查robots.txt
- 标注数据来源
- 尊重版权和许可
- 教育用户合规使用

### DON'T ❌
- 绕过技术保护措施
- 爬取需要登录的内容
- 忽视网站使用条款
- 大规模复制版权内容
- 隐瞒数据来源

## 竞争优势

通过合规的数据收集策略，Metra可以：
1. 避免法律风险
2. 建立用户信任
3. 获得高质量数据
4. 实现可持续发展
5. 树立行业标杆
